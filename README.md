## 💻 วิธีการติดตั้งและใช้งาน (How to Execute)

1. เปิดเกม Roblox ที่คุณต้องการเล่น (ต้องตรงกับสคริปต์ที่มี)
2. เปิด Executor (เช่น Potassium,madium,Wave,volt  หรืออื่นๆ ที่รองรับ)
3. เลือกโค้ดรันเนอร์ด้านล่างนี้ไปวางใน Executor แล้วกดปุ่ม `Execute`
